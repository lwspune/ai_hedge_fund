# Market Intel dashboard

Read-only web view of the market-intelligence platform: the Desk (open buybacks, rights
entitlements, anchor unlocks), signal verdicts, bulk data and company pages. Vite + React +
supabase-js, hash-routed, no router or UI kit. Deployed on Vercel.

**Env vars** (`dashboard/.env`, or Vercel project settings; see `.env.example`):
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`. The anon key is read-only under RLS.
Never put the service-role key in a `VITE_` variable.

**Scripts:** `npm run dev` · `npm test` (vitest, pure logic in `src/lib`) · `npm run lint` ·
`npm run build`.

**Signals:** `src/signals.json` is generated by `scripts/emit_signals_json.py` from
`scanner/catalog.py`; display copy lives in `src/lib/signalLabels.js`.

**Design:** tokens in `src/styles/tokens.css`; spec in `docs/DASHBOARD_REDESIGN_SPEC.md`.
